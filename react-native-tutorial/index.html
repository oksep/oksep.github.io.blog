以 Android 为例

  • 1.初始项目发布时，生成并保留一份 bundle 文件。
  • 2.有版本更新时，生成新的 bundle 文件，
  • 3.使用 google-diff-match-patch 对比两个文件，并生成差异补丁文件。
  • 4.App 下载补丁文件，再使用 google-diff-match-patch 和 assets 目录下的初始版本合并，生成新的 bundle 文件。
